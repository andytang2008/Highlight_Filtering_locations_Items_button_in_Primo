Highlight “Filtering Locations Items” Button in Primo

Some librarians have discussed improving the physical items sort routine so that call numbers I–J–K sort in descending order while A–B–C sort in ascending order.
(See: Ex Libris Idea Exchange suggestion
)

If such a feature is implemented, it would greatly improve usability for patrons. However, until that functionality becomes available, a temporary solution is to highlight the “Filtering Locations Items” button to draw patrons’ attention. This visual cue reminds users that they can use the filter to display the correct order and sequence of multi-volume monographs—without having to scroll through the entire list.

Relying on reference librarians to teach every patron individually is not practical, so this JavaScript solution provides a lightweight, proactive reminder within the Primo interface.

This is only a temporary workaround. The ideal long-term solution will depend on Ex Libris backend development implementing a sorting algorithm that adapts to different contexts.

After applying this code, the multi-volume monograph display page will highlight the filter button in an eye-catching color, encouraging patrons to use it as an alternative way to quickly retrieve items in the proper sequence.
